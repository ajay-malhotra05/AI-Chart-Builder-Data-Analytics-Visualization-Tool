# 📊 AI Chart Builder — Data Analytics & Visualization Tool

An interactive data analytics and visualization tool designed to help users explore datasets, build data-processing workflows, and create meaningful visualizations with ease.

## ✨ Features

- 📁 **Data Preview** — Inspect dataset contents before analysis.
- 🔍 **Query Builder** — Build data queries and customize analysis workflows.
- ⚙️ **Data Processing Pipeline** — Organize data-processing operations into a structured pipeline.
- 📈 **Data Visualization** — Turn data into charts and visual insights.
- 🧪 **Sample Data** — Explore the tool using sample datasets.
- 💻 **Modern Interface** — A clean interface built with modern frontend technologies.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** CSS
- **Data Processing:** Python (requirements included)
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Python, if required by the project's data-processing components

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ajay-malhotra05/AI-Chart-Builder-Data-Analytics-Visualization-Tool.git
   ```

2. Navigate to the project folder:

   ```bash
   cd AI-Chart-Builder-Data-Analytics-Visualization-Tool
   ```

3. Install the frontend dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
